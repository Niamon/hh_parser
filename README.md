Проект для поиска вакансий через API HeadHunter, сохранения их в PostgreSQL и построения простой статистики.
Запросы сохраняются в кэш, с каждым запуском бд очищается и заполняется по новой, данные можно анализировать через графики.
Конфигурация базы хранится в .env, чувствительные данные не попадают в репозиторий. Необходимо добавить свой файл .env, пример в src

Запуск можно осуществить:
pip install -e .
  1 hhparser
  2 python -m scripts.run --query "..."
  3 python main.py
